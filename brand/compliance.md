# Compliance notes (Fusion Markets landings)

Keep these in mind when generating copy. Final legal sign-off is still marketing/compliance — this file is a guardrail, not a license to publish.

## Always include

- CFD / leverage risk warning on every marketing landing.
- Avoid presenting previews as official live campaigns until approved.

## Claims to treat carefully

- “Lowest cost”, “industry-leading”, “best”, absolute ranking claims → need substantiation / footnotes as on the live site.
- Performance / withdrawal speed numbers → only with approved wording and qualifiers.
- Regulatory status → use approved entity wording only.

## Preview domain

- Hosted on `fm.growth-agent.org` (internal Growth Agent infrastructure).
- All pages ship with `noindex, nofollow`.
- Do not run paid ads to these URLs without an explicit decision.
